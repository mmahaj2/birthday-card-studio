# Birthday Card Studio

A responsive, standalone birthday-card message generator. It uses plain HTML, CSS and JavaScript — no build step, framework, database, login or API key required.

## Run locally

1. Download and unzip the project.
2. Open `index.html` in a modern browser.

For a local development server, you can also run:

```bash
npx serve .
```

Then open the local URL printed in your terminal.

## Deploy publicly with Vercel

### Option A — Deploy from GitHub (recommended)

1. Create a GitHub account if you don't already have one: https://github.com/
2. Create a **new public or private repository**, for example `birthday-card-studio`.
3. Upload these project files to the repository root:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `README.md`
4. Sign in to Vercel: https://vercel.com/
5. Choose **Add New → Project** and import your GitHub repository.
6. Configure the project:
   - Framework Preset: **Other**
   - Root Directory: `./`
   - Build Command: leave blank
   - Output Directory: leave blank (or `.` if Vercel asks for one)
   - Install Command: leave blank
7. Select **Deploy**.
8. Vercel will provide a public URL such as `https://birthday-card-studio.vercel.app`. Share that URL with anyone.

Every future push to the connected GitHub branch will trigger a new deployment automatically.

### Option B — Deploy with the Vercel CLI

1. Install Node.js from https://nodejs.org/
2. Install the Vercel CLI:

```bash
npm install -g vercel
```

3. In a terminal, change directory into this project folder.
4. Run:

```bash
vercel
```

5. Follow the prompts. When ready to publish to production, run:

```bash
vercel --prod
```

## Custom domain

In your Vercel project, open **Settings → Domains**, add a domain you own, and follow Vercel's DNS instructions. A custom domain is optional.

## How it works

- Visitors enter a name, age and hobby.
- They choose one of five humour styles.
- The app creates a message from local templates and shows it inside the open birthday card.
- Visitors can generate another version, copy the message or print the card.

## Privacy and limitations

- No account, database or server is required.
- Names, ages and hobbies are processed in the visitor's browser and are not sent to a server by this app.
- Google Fonts are loaded from Google Fonts when internet access is available; system fonts are used as fallbacks.
- Messages are template-based, not generated by an AI service. This keeps the site free to host and avoids exposing an AI API key.
- The site is static, so there are no ongoing backend services to maintain.
